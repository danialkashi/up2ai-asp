# انتشار روی IIS با یک کلیک

روی سرور، داخل کلونِ همین ریپو، روی `deploy\deploy.bat` دوبار کلیک کنید. اسکریپت این کارها را خودکار انجام می‌دهد:

1. آخرین کد را `git pull` می‌کند.
2. پروژه را با `dotnet publish -c Release` می‌سازد.
3. در اولین اجرا، مشخصات PostgreSQL و رمز پنل مدیریت را می‌پرسد و فایل `appsettings.Production.json` را فقط روی سرور می‌سازد. اجراهای بعدی این فایل را دست نمی‌زنند.
4. اگر app pool و سایت IIS نباشند، آن‌ها را می‌سازد. app pool روی No Managed Code تنظیم می‌شود.
5. سایت را با `app_offline.htm` موقتاً پایین می‌آورد، فایل‌ها را کپی می‌کند و دوباره بالا می‌آورد.
6. در پایان بررسی می‌کند که سایت پاسخ 200 بدهد، و نتیجه را سبز (موفق) یا قرمز (خطا) نشان می‌دهد.

عکس‌های وبلاگ (`wwwroot\uploads`)، پوشه‌ی `logs` و `appsettings.Production.json` در هر انتشار حفظ می‌شوند. جدول‌های دیتابیس را خود برنامه موقع بالا آمدن می‌سازد و migration جداگانه‌ای لازم نیست.

## پیش‌نیازهای سرور (یک بار)

- IIS
- [.NET 10 Hosting Bundle](https://dotnet.microsoft.com/download/dotnet/10.0)، که بعد از نصب IIS نصب شود.
- .NET 10 SDK و Git
- PostgreSQL، که می‌تواند روی همین سرور باشد یا روی یک سرور دیگر.

## تنظیمات

بالای `deploy.ps1` این مقادیر قابل تغییرند: نام سایت، نام app pool، مسیر سایت (پیش‌فرض `C:\inetpub\up2ai`)، پورت و دامنه.
اگر Default Web Site روی پورت 80 روشن است، یا `$HostName` را روی دامنه‌ی خودتان بگذارید یا پورت را عوض کنید.
