# انتشار روی IIS با یک کلیک

روی سرور، داخل کلونِ همین ریپو، روی `deploy\deploy.bat` دوبار کلیک کنید. اسکریپت این کارها را خودکار انجام می‌دهد:

1. قبل از هر کاری آخرین کد را `git pull` می‌کند، تا نسخه‌ی جدید خودِ اسکریپت هم اجرا شود.
2. پروژه را با `dotnet publish -c Release` می‌سازد.
3. هیچ سؤالی نمی‌پرسد. تنظیمات دیتابیس و ادمین از `appsettings.Production.json` داخل پوشه‌ی سایت خوانده می‌شود (اگر وجود داشته باشد؛ در هر انتشار حفظ می‌شود)، وگرنه از `appsettings.json` و متغیرهای محیطی.
4. روی سایت `up2ai.ir` در IIS منتشر می‌کند: پوشه و app pool را از خود سایت می‌خواند و به binding و گواهی SSL دست نمی‌زند. app pool روی No Managed Code تنظیم می‌شود. اگر سایت وجود نداشته باشد، آن را می‌سازد.
5. سایت را با `app_offline.htm` موقتاً پایین می‌آورد، از پوشه‌ی فعلی در `<مسیر سایت>-backup` نسخه‌ی پشتیبان می‌گیرد، فایل‌های جدید را کپی می‌کند و سایت را دوباره بالا می‌آورد. برای برگشت به نسخه‌ی قبل، کافی است محتوای پوشه‌ی backup را دوباره به پوشه‌ی سایت کپی کنید.
6. در پایان بررسی می‌کند که سایت پاسخ 200 بدهد، و نتیجه را سبز (موفق) یا قرمز (خطا) نشان می‌دهد.

عکس‌های وبلاگ (`wwwroot\uploads`)، پوشه‌ی `logs` و `appsettings.Production.json` در هر انتشار حفظ می‌شوند. جدول‌های دیتابیس را خود برنامه موقع بالا آمدن می‌سازد و migration جداگانه‌ای لازم نیست.

## پیش‌نیازهای سرور

اسکریپت پیش‌نیازها را خودش نصب می‌کند. اگر هر کدام از این‌ها نباشد، آن را از سایت مایکروسافت دانلود و بی‌صدا نصب می‌کند و بعد دوباره بررسی می‌کند:
- IIS
- .NET 10 Hosting Bundle (بعد از نصب، IIS را هم ری‌استارت می‌کند)
- .NET 10 SDK

فقط این دو مورد را باید خودتان آماده کنید:
- Git، که برای کلون و pull لازم است.
- PostgreSQL، که می‌تواند روی همین سرور باشد یا روی یک سرور دیگر.

سرور برای نصب خودکار به اینترنت نیاز دارد. اگر بعد از نصب پیام «Restart the server» آمد، سرور را یک بار ری‌استارت کنید و دوباره اسکریپت را اجرا کنید.

## تنظیمات

بالای `deploy.ps1` نام سایت IIS تنظیم می‌شود (پیش‌فرض `up2ai.ir`). بقیه‌ی مقادیر آن‌جا، یعنی مسیر، app pool، پورت و دامنه، فقط وقتی استفاده می‌شوند که سایت وجود نداشته باشد و اسکریپت بخواهد آن را بسازد.
